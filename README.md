# byGauthier — Sonic Architect

Landing page for byGauthier (music composer/producer): loading intro, gate,
video hero with ambient soundscape, and a "Start a project" flow into a
contact form.

Static site — `index.html` + `assets/`. No build step.

## Local preview

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.
